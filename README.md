# 🚀 SPACE GAMBLE

우주선 비상 사출 장치 앞에 마주 앉아 벌이는 1대1 심리전 게임입니다. 자신의 숫자는 모른 채 상대의 숫자와 비언어적 행동(시선)만을 읽고 눈치 싸움을 진행합니다. 단 한 번이라도 사출 사고가 발생하면 즉시 패배합니다.

## 🛠 기술 스택 (Tech Stack)
* **Engine:** Unity 6 (URP)
* **Network:** Netcode for GameObjects (NGO) + Unity Relay (DTLS)
* **Packages:** DOTween, TextMeshPro, Timeline
* **Platform:** PC (Windows)

## 🎲 핵심 룰 (How to Play)
1. **카드 배분:** 라운드마다 1~10 사이의 숫자를 무작위로 받습니다. 내 숫자는 보이지 않고 **상대방의 숫자만** 보입니다.
2. **선택 (20초):** 상대를 관찰하며 3가지 액션 중 하나를 몰래 선택합니다.
   * `GO`: 그대로 승부 진행
   * `FOLD`: 해당 라운드 무효화 (게임당 2회 제한)
   * `OVERLOAD`: 이번 라운드의 사출 확률 일시적 증폭 (1.5배~2배)
3. **버튼 판정:** 숫자가 더 낮은 사람이 자신의 사출 버튼을 누릅니다.
4. **확률 누적:** 버튼을 눌러 살아남으면 사출 확률이 증가하여 다음 라운드에 누적됩니다. 라운드가 거듭될수록 사출 확률이 조여옵니다.

## 💡 주요 구현 특징 (Key Features)

### 1. 엄격한 서버 권위 (Server-Authoritative) 아키텍처
* 난수 생성, 승패 판정, 확률 계산 등 모든 핵심 로직은 호스트(서버)가 전담하는 `GameManager`와 순수 C# 클래스인 `GameSession`에서 처리됩니다.
* **정보 통제 (Anti-Cheat):** "클라이언트에 없는 정보는 훔칠 수 없다"는 원칙 하에, 내 숫자나 상대의 FOLD 잔여 횟수 등 게임 진행에 아직 필요하지 않은 데이터는 서버가 클라이언트로 아예 전송하지 않습니다.

### 2. 1인칭 시선 동기화 (Head Look Sync)
* 플레이어의 유일한 비언어적 표현 수단인 **시선(머리 회전)**을 네트워크 너머로 동기화합니다.
* Animator가 본 포즈를 덮어쓰는 문제를 해결하기 위해 `LateUpdate`에서 캐릭터 기준 축을 바탕으로 회전값을 재계산하여 자연스러운 시선 처리를 구현했습니다.

### 3. 다이제틱 UI 및 3D 레이캐스트 상호작용
* 1인칭 커서 잠금 상태를 유지하면서 몰입감을 높이기 위해, 스크린 UI 대신 공간에 배치된 물체(홀로그램, CRT 모니터, 좌석 패널)를 UI로 활용합니다.
* 마우스 클릭 시 화면 정중앙(조준점)에서 3D Ray를 발사하여 오브젝트와 상호작용하도록 설계되었습니다 (`ChoiceTarget`, `PressTarget`).

### 4. 이벤트 기반의 유연한 연출 지휘
* UI 컴포넌트들은 서버 데이터를 직접 참조하지 않고 `GameClient`가 노출하는 C# 이벤트를 구독하여 화면을 갱신합니다.
* `CenterHologram`이 연출 지휘자 역할을 맡아 타임라인, 애니메이션 이벤트(손이 레버에 닿는 프레임 동기화), DOTween 효과 등을 순차적으로 제어합니다.
